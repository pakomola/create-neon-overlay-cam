# Create Neon Overlay Cam for Streamers

Aplicación ligera y profesional para creadores de contenido y streamers que permite añadir un marco de cámara estilo neón totalmente personalizable sobre OBS Studio, Streamlabs y otros softwares de emisión.

## Características
- Marcos de neón personalizables en tiempo real.
- Bajo consumo de CPU y GPU.
- Configuración rápida e intuitiva.
